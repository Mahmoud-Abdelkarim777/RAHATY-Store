# 🛍️ [RAHATYStore](https://rahaty-store.vercel.app/) — E-Commerce Website

**RAHATYStore** is a responsive e-commerce website built with React, designed to provide a smooth and user-friendly online shopping experience. Users can browse products, explore categories, search for items, manage their shopping cart and favorites, and authenticate through a login page.

## ✨ Features

- 🏠 **Home Page** — Hero slider and featured products.
- 🛍️ **Products** — Browse and explore available products.
- 🗂️ **Categories** — Discover products by category.
- 🔎 **Search** — Find products quickly.
- 📦 **Product Details** — View individual product information.
- 🛒 **Shopping Cart** — Add and remove products from the cart.
- ❤️ **Favorites** — Save favorite products for later.
- 🔥 **Deals** — Explore discounted products.
- 🔐 **Authentication** — Login using the DummyJSON authentication API.
- 📱 **Responsive Design** — Adapted for mobile, tablet, and desktop screens.

## 🛠️ Technologies Used

- React
- Vite
- Tailwind CSS
- React Router
- Axios
- Swiper
- DummyJSON API
- JavaScript (ES6+)
- HTML5

## 🚀 Getting Started

### Installation

1. Clone the repository:

   git clone https://github.com/Mahmoud-Abdelkarim777/RAHATY-Store

2. Navigate to the project directory:

   cd E-Commerce

3. Install dependencies:

   npm install

4. Start the development server:

   npm run dev

5. Open the local URL displayed in your terminal.

## 🌐 API

This project uses the [DummyJSON API](https://dummyjson.com/) to retrieve product data, categories, and authentication information.

No custom backend is required to run the project.
